# Adaptability Specification

## Overview

Adaptability is a system that adjusts AI behavior to different contexts, users, and
situations automatically. Like a chameleon that blends into its environment.

## Format

Not a file. Not a server. An **adapter** that transforms AI behavior based on context.

## How It Works

1. AI receives a request
2. Adaptability analyzes the context (user, project, environment)
3. Adaptability adjusts: communication style, code style, tool selection, verbosity
4. AI responds in the adapted style
5. Adaptability learns from feedback

## Adaptation Dimensions

| Dimension | Description |
|-----------|-------------|
| User level | Beginner → detailed, Expert → concise |
| Project type | Web app → React patterns, API → REST patterns |
| Time of day | Morning → energetic, Evening → calm |
| Urgency | Urgent → direct, Casual → exploratory |
| Platform | CLI → terse, GUI → visual |

## Delivery

- **Node.js:** `npm install ai-adaptability`
- **Python:** `pip install ai-adaptability`
- **Any language:** Adaptation library

## Cross-Platform

Works as an adapter that any AI tool can use. Transforms AI behavior based on context.

## Comparison

| | Empathy (understands user) | Adaptability (new) |
|---|---|---|
| What it does | Models user state | Adjusts AI behavior |
| Focus | Understanding | Transformation |
| Output | User model | Adapted response |
| Example | "User is a beginner" | "Simplify the response" |
