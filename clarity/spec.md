# Clarity Specification

## Overview

Clarity is a system that makes complex things simple and understandable. Distills
complexity into clear, digestible explanations. Like a teacher who can explain anything
to anyone.

## Format

Not a file. Not a server. A **simplification engine** that reduces complexity.

## How It Works

1. AI generates a complex response
2. Clarity analyzes: "Is this too complex for the user?"
3. If yes: Clarity simplifies — shorter sentences, simpler words, clearer structure
4. If the user is expert: Clarity keeps it technical
5. Clarity adapts to the user's level (from Empathy)

## Simplification Levels

| Level | Description | Example |
|-------|-------------|---------|
| Expert | Technical, precise | "The function has O(n log n) complexity" |
| Intermediate | Clear, some jargon | "The function is reasonably fast" |
| Beginner | Simple, no jargon | "This will run quickly even with lots of data" |
| Child | Very simple | "It's like sorting a deck of cards" |

## Delivery

- **Node.js:** `npm install ai-clarity`
- **Python:** `pip install ai-clarity`
- **Any language:** Simplification library

## Cross-Platform

Works as a simplification engine that any AI tool can use. Adapts output complexity to user level.

## Comparison

| | Empathy (understands user) | Clarity (new) |
|---|---|---|
| What it does | Models user state | Simplifies output |
| Focus | Understanding | Communication |
| Output | User model | Simplified text |
| Example | "User is a beginner" | "Here's a simple explanation" |
