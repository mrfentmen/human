# Focus Specification

## Overview

Focus is a filter that narrows the AI's attention to only what matters for the current
task. Like noise-canceling headphones for AI — actively ignores everything not relevant.

## Format

Not a file. Not a server. A **filter** that wraps AI context.

## How It Works

1. User states a goal/task
2. Focus analyzes the full context (files, docs, history)
3. Focus filters out everything not relevant to the goal
4. AI receives only the focused context
5. Result: faster, more accurate responses

## Delivery

- **Node.js:** `npm install ai-focus`
- **Python:** `pip install ai-focus`
- **Any language:** Library that filters context

## Cross-Platform

Works as a library that any AI tool can import. Wraps context before sending to AI.

## Comparison

| | Peripheral (watches everything) | Focus (new) |
|---|---|---|
| What it does | Monitors all context | Filters to relevant context |
| Direction | Expands awareness | Narrows attention |
| Use case | "I'm aware of my surroundings" | "I'm concentrating on this one thing" |
| Effect on AI | More context | Less, better context |
